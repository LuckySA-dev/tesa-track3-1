# วิธีเปิดใช้งาน practice-web (เว็บฝึก + เครื่องมือกลยุทธ์)

เว็บนี้รันบนเครื่องตัวเองทั้งหมด ไม่ส่งข้อมูลไปตลาดแข่งจริง ใช้ได้ทั้งซ้อมและเป็นผู้ช่วยคำนวณระหว่างแข่ง

## 1. สิ่งที่ต้องมี

- Python 3.10 ขึ้นไป (เช็กด้วย `python --version`)
- โฟลเดอร์ต้องอยู่ครบแบบนี้ เพราะเว็บเรียกโค้ดจาก `agent/`, `tools/` และ `vendor/TesaMarket-build`

```
CoffeeT3/
├── practice-web/             ← เว็บ (ไฟล์นี้อยู่ที่นี่)
├── agent/                    ← market_core.py pricing.py planner.py strategy.py appraisal.py memory.py
├── tools/                    ← sim.py manual_helper.py arena.py research_tools.py
├── vendor/TesaMarket-build/  ← เครื่องจับคู่และบอทของตลาดฝึก
└── tests/
```

เว็บใช้แค่ไลบรารีมาตรฐานของ Python ไม่ต้อง `pip install` อะไรเพิ่ม (venv ต้องใช้เฉพาะตอนรัน pytest หรือ agent `agent/main.py`)

## 2. เปิดเว็บ

เปิด Terminal ที่โฟลเดอร์ `CoffeeT3` (ไม่ใช่ในโฟลเดอร์ `practice-web`) แล้วรัน

```bash
python -B practice-web/app.py
```

ถ้าสร้าง venv ไว้แล้ว ใช้ตัวนี้ก็ได้

```bash
.venv/Scripts/python -B practice-web/app.py
```

เมื่อขึ้นข้อความ `Day 1: http://127.0.0.1:8765/trade` ให้เปิดเบราว์เซอร์ไปที่

- หน้าหลัก: **http://127.0.0.1:8765/trade**
- หน้างานวิจัย: **http://127.0.0.1:8765/research**

ปิดเว็บ: กด `Ctrl + C` ในหน้าต่าง Terminal

### พอร์ตถูกใช้อยู่

ถ้าขึ้น error ว่าพอร์ต 8765 ถูกใช้ ให้เปลี่ยนพอร์ต แล้วเปิด URL ตามที่หน้าต่างแสดง

```bash
python -B practice-web/app.py --port 8766
```

## 4. กติกาที่ต้องจำ

- **17 พ.ย.** ยื่นซองในหน้า /trade ของผู้จัด **ด้วยมือเท่านั้น** · เว็บนี้แค่คำนวณ ห้ามใช้สคริปต์ส่งซอง
- **18 และ 20 พ.ย.** agent ต้องส่งเองทั้งหมด · ห้ามยื่น แก้ หรือยกเลิกซองด้วยมือ
- LLM ใช้ได้เฉพาะ `event-llm` ของงานเท่านั้น
- ปุ่ม "ยื่นตามคำแนะนำ" ในแท็บตลาดฝึกยื่นเข้า **ตลาดฝึกบนเครื่องนี้** เท่านั้น

## 5. ข้อมูลถูกเก็บที่ไหน

- เกมในตลาดฝึกอยู่ในหน่วยความจำของ Python · ปิดโปรแกรมแล้วเริ่มใหม่ · ทุกแท็บบนเครื่องเห็นเกมเดียวกัน
- ใบประเมินมูลค่า แข่งรอบ 1 และประวัติในหน้า /research เก็บใน `localStorage` ของเบราว์เซอร์ · ปิดแล้วเปิดใหม่ยังอยู่ แต่จะหายถ้าล้างข้อมูลเบราว์เซอร์หรือเปิดโหมดไม่ระบุตัวตน
- สำรองข้อมูลรอบ 1: แท็บแข่งรอบ 1 → "ประวัติทุกรอบ / สำรองข้อมูล" → คัดลอกข้อความเก็บไว้ (ใช้กับ `python tools/manual_helper.py` ได้)

## 9. ใช้แข่งจริงกับทีมคน (แท็บ "แข่งสด · manual")

ระบบไม่ส่งอะไรไปตลาดจริง · ดูคำแนะนำแล้ว **พิมพ์ซองใน /trade เอง**

**ก่อนเริ่ม**
1. แท็บใบประเมินมูลค่า: กรอก 4 ล็อต → ส่ง TV ที่ขึ้นในการ์ด "ส่งผลประเมินมูลค่า"
2. แท็บแข่งสด: กด "ดึงจากใบประเมินมูลค่า" · ตั้งจำนวนรอบ
3. วันที่ 18/20: ใส่ "ขายได้ต่อรอบสูงสุด" = capacity_left_kg ÷ 60 และเว้นขอบสเปก เสีย 0.2 / ชื้น 0.15 (ตัวอย่างมี noise)

**ทุกรอบ**
1. "+ RFQ" ทีละใบตามหน้า /trade (รหัส ชื่อผู้ซื้อ ประเภท กระสอบ)
2. ตั้งกลยุทธ์ (ไม่ตั้งก็ได้ ค่าเริ่มต้นดีที่สุดในการจำลอง):
   - **ขายรอบนี้** เอาเครื่องหมายออก = ไม่ขายเลยรอบนี้
   - **ความเสี่ยง** สมดุล (แนะนำ) / ปลอดภัย / กล้าเสี่ยง
   - **ขายอย่างน้อย / ไม่เกิน** กี่กระสอบรอบนี้
   - **เป้า PR** เช่น 96 → บอก k เฉลี่ยที่ของเหลือต้องได้ · ติ๊ก "ห้ามขายต่ำกว่า" ถ้าจะบังคับ
   - ตารางล็อต คอลัมน์ "รอบนี้": อัตโนมัติ / ไม่ขาย / ขายพอดี N / ไม่เกิน N และ "k ขั้นต่ำ %"
   - แถวล่างของ RFQ: ข้าม · ราคาเรา (บาท หรือ k %) · ไม่เกินกี่กระสอบ · **ราคาคู่แข่งต่ำสุดที่เห็น** (บาท หรือ k %)
3. กด "คำนวณราคาแนะนำ" → พิมพ์ "ราคา (บาท/กก.)" และ "กระสอบ" ลง /trade → ติ๊ก "ยื่นแล้ว"
4. หลังจับคู่: "สร้างแถวจากซองที่แนะนำ" → เลือกผลทุกซอง · กรอกภาพรวมตลาด (ซื้อได้ · ข้อเสนอ · ราคาต่ำ/สูง)
5. "บันทึกผลและไปรอบถัดไป"

**อ่านส่วนคู่แข่ง**: ผู้ซื้อที่ "ซื้อไม่ครบ" = คนน้อย ตั้งชิดเพดานได้ · "ซองเฉลี่ย ≥ 8" = แย่งกันเยอะ ต้องต่ำกว่า "k ตัดล่าสุด"
